# Forguncy 주간보고 데모

Forguncy(노코드 플랫폼)로 구현한 **주간보고** 데모입니다.
팀원별 업무 실적 입력, 취합, 조회 등 주간보고 업무를 노코드로 구축한 예시를 확인할 수 있습니다.

## 🔗 데모 바로가기

👉 [데모 실행하기](https://demo.forguncy.co.kr/weeklyreport)

## 📋 주요 기능

- 주간 업무 실적 입력
- 팀/부서별 보고 취합
- 보고서 조회 및 열람
- 보고 이력 관리

## ℹ️ Forguncy란?

Forguncy는 코딩 없이 드래그 앤 드롭 방식으로 웹 애플리케이션을 만들 수 있는 MESCIUS의 노코드 개발 플랫폼입니다. 주간보고, 프로세스 관리, 인사평가, 재고관리 등 다양한 업무용 애플리케이션을 빠르게 구축할 수 있습니다.
